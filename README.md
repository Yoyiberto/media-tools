# media-tools

Media tools so you can create high quality subtitles using AI.
For example Using Whisper from OpenAI or LLMs in general.

## Whisper-large.ipynb
Using Whisper it creates .srt for all the files inside a folder. Options from whisper are available like language, model size, input directory.
